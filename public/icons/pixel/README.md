# Pixel World icons

Nine original 12×12 SVG icons drawn from integer grids in `scripts/generate-pixel-icons.mjs`. Covered by the repository's MIT license. No external font, bitmap, image service or icon license is required.

Edit the grids/palettes in the generator, run `node scripts/generate-pixel-icons.mjs`, then `npm test`. Keep the checked-in SVGs in sync. Files are served directly as decorative images inside labelled map buttons. Category names remain accessible text; mystery icons deliberately share one appearance.
